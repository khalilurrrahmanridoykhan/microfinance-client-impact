# Dashboard

The CI8 dashboard is a static Vite and TypeScript app in `web/`. It reads only aggregate
JSON files from `web/public/data/`, generated by:

```sh
make webdata
cd web
npm install
npm test
npm run build
```

## Views

- **Overview:** paired-client count, support-review signal rate and satisfaction response count.
- **Financial health:** debt-service and multiple-borrowing signals.
- **Inclusion & voice:** reported agency, satisfaction and complaint rate.
- **Methods:** uncertainty interval and causal-readiness status.

Every view carries the synthetic-data boundary. No client-level records are exported to the
dashboard, and no displayed signal is an automatic credit decision.

## Publication checks

Before publishing a dashboard build, verify:

- `make webdata` is reproducible;
- aggregate JSON remains valid and contains no `client_id` field;
- `npm test` and `npm run build` pass;
- keyboard navigation and narrow-screen layout remain usable; and
- methods, uncertainty and causal-readiness text remains visible.

The initial `npm install` audit reported dependency advisories from the Vite/Vitest toolchain.
They should be reviewed and resolved through a deliberate dependency update before a
production deployment; no breaking audit fix is applied automatically.
